# အမ    သ  ပည  ရ  ပ ဒ

(၂၀၁၄     စ ၊  ပည  ထ င စ လ တ  တ   ပ ဒအမ တ  ၄၁ ။)

၁၃၇၆     စ ၊  သ တင    တ လဆန    ၇ ရ

(၂၀၁၄     စ ၊   စ  တင ဘ လလ  ၃၀ ရ  )

ပည  ထ င စ လ တ  တ  သည    ပ ဒ    ပ  န  လ   သည ။

## အ န  (၁) အမည   င အဓ ပ  ယ  ဖ   ပ

### ၁။
ပ ဒ   အမ    သ  ပည  ရ  ပ ဒ ဟ    တ င  စရမည ။

### ၂။
ပ ဒတ င  ပ ရ  သ   အ   ပ စ   ရပ မ   သည   ဖ   ပပ အတ င   အဓ ပ  ယ သ   ရ စရမည  -

( ) င င  တ   ဆ သည မ    ပည  ထ င စ သမ တ မန မ   င င  တ     ဆ သည ။

(   ) အစ  ရအဖ     ဆ သည မ     ပည  ထ င စ သမ တ မန မ   င င  တ     ပည  ထ င စ အစ  ရ အဖ       ဆ သည ။

( ဂ ) မရ င  ဆ သည မ     ပ ဒ ပ ဒ မ ၅ အရ  ဖ   စည  ထ  သည  အမ    သ  ပည  ရ မရ င     ဆ သည ။

(ဃ) ဝန     ဌ န ဆ သည မ    ပည  ထ င စ အစ  ရ ပည  ရ ဝန     ဌ န   ဆ သည ။

( င ) သ  ဆ င ရ ဝန     ဌ န ဆ သည မ     ပ ဒ   အ   င အထည  ဖ    ဆ င ရ   ရန အစ  ရအဖ     တ ဝန  ပ အပ  သ   ပည  ထ င စ ဝန     ဌ န   ဆ သည ။

( စ ) ဒသဆ င ရ အ ပ    ပ  ရ အဖ     ဆ သည မ    တ င   ဒသ      သ    မဟ တ    ပည နယ အစ  ရအဖ   ၊    ယ ပ င အ ပ    ပ   င ရတ င    သ    မဟ တ     ယ ပ င အ ပ    ပ   င ရ ဒသ စ  အဖ    ၊  ပည  ထ င စ နယ   မ၊    င ၊  မ     နယ   င ရပ      သ    မဟ တ      ရ  အ ပ စ အ ပ    ပ  ရ ဆ င ရ အဖ   အသ  သ     ဆ သည ။

(ဆ) အမ    သ  ပည  ရ ဆ သည မ င င  တ  ရ   တ င  ရင  သ  အ  လ     ဘ သ စ   ၊ စ  ပ၊ ယ      မ ၊ အ  ပည ၊    ရ ဓ လ   င  သမ င  အ မ အ  စ မ အ  စ သ ရမ       တန ဖ  ထ  ထ န  သ မ   မ င တင  ပ    ဘ  စ အ တ  အ     မ န  န ၍

( ဇ ) သင ယ သ   ဆ သည မ    မ မ  အရည အ  င  တ  တ   စရန   ပည  ရ လမ      င အလ     ပည  ရ အဆင   င အတန  တ င ရရ   င သည   ပည သင     မ နည  စနစ မ င အည  ရ   ဖ   ယ   လ လ သင ယ သ  သ    မဟ တ      င  သ     ဆ သည ။

( ဈ ) ဆရ  ဆ သည မ   ပည  ရ အဆင တစ     တ င  သင      ရ  တ ဝန ထမ   ဆ င  သ သတ မ တ အရည အ  င    င   ပည စ သည  သင     ပ      သ    ဆ သည ။

(ည) င  ပည  ရ   ဆ သည မ    သင ယ သ    အသ  အရ ယ ၊  သင ယ ရမည   အ   န လ၊  နရ ၊ အတန  ၊ ပည ရည စစ  ဆ တ င  တ မ စနစ   င တ    သ  သင န  တမ   ဖင   သင      ပ  သ       င  အ    ပ   မ     ပည  ရ ၊  မ လတန ပည  ရ ၊ အလယ တန  ပည  ရ ၊ အထ  တန  ပည  ရ ၊ နည  ပည   င  သ   မ ပည  ရ   င  အဆင  မင ပည  ရ တ   အ       ဝင သည ပည  ရ    ဆ သည ။

( ဋ ) င   ပင ပပည  ရ   ဆ သည မ    သင      န  တမ  မ       အ     ၍  သင ယ လ သ မ ပည ရည  မင မ  လ  စရန         င  ပည  ရ စနစ    ပင ပတ င    ပင ဆင   ပ င  လ င  သ  နည  လမ  မ    ဖင  စည     သင      ပ သည  ပည  ရ    ဆ သည ။

( ဌ ) တန  ည ပည  ရ အစ အစ ဆ သည မ င   ပင ပ ပည  ရ အစ အစ  အရ သင ယ ရရ သည   ပည အဆင အတန          င  ပည  ရ   အဆင အတန  မ     င အရည အ  င   ည   င  သတ မ တ  ပ  သ  အစ အစ     ဆ သည ၊၊

( ဍ ) ယ တ င သင ယ ပည  ရ  ဆ သည မ   မ မ လ အပ       င  စ တ ဝင စ  မ အရ မ မ ယ တ င သတ မ တ သင ယ  သ  ပည  ရ   ဆ သည ။

( ဎ ) ရ    အရ ယ   လ သ ငယ ပည  ရ   ဆ သည မ     မ  စမ အသ  ရ စ   စ    ပည သည အရ ယ အထ လ သ ငယ မ ဘ  စ ဖ     ဖ   မ ရရ  စရန ၊ ဖ     ဖ   မ အဆင   င ည  သ   နည  လမ  မ       အသ   ပ  ပ     ပ စ ပ     ထ င  ပ  သ   ပည  ရ ဆ သည ။

(ဏ) မ     ပည  ရ   ဆ သည မ    အသ  သ    စ မ   င    စ အရ ယ     လ မ        ယ၊ ဉ ဏ၊ စ ရ တ   ၊ မ တ     င စ တ ပ င  ဆ င ရ  ဖ     ဖ   တ  တ   ရ   င အ     ပည  ဆ  လ သင ယ   င  ရ တ    အတ     ပ စ ပ     ထ င  ပ  သ ပည  ရ    ဆ သည ။

(ထ) အ     ပည  ရ   ဆ သည မ      င င သ  တ င    တတ   မ   ရန   သတ မ တ ထ   သ ပည အ သင ယ တတ   မ    စရန   င နည  ပည   င သ   မ  ပည ရပ တစ          ဖစ  စ၊  အဆင  မင ပည      ဖစ  စ  ဆ  လ  သင ယ   င  စရန  သင လ   င  ပ သည  ပည  ရ    ဆ သည ။

( ဒ ) နည  ပည   င သ   မ  ပည  ရ ဆ သည မ လ   တ    နည  ပည   မ    င သ မ   ၊ စ  မ လ  မ အတတ ပည ရ င မ   ၊    မ    င သ မ     င   သ   မ  ပည ရပ ဆ င ရ အသ ပည ရ င မ   ၊ အတတ ပည ရ င မ   ၊   မ    င သ မ      စနစ တ    မ  ထ တ ပ သည  ပည  ရ    ဆ သည ။

( ဓ ) အဆင  မင ပည  ရ   ဆ သည မ    အ     ပည  ရ    အ မင ဆ  အဆင   သ   မဟ တ ယင    င  တ ည  သ အဆင   အ င  မင  ပ  သ မ      အမ    သ  ပည  ရ      မရ င အသ အမ တ  ပ ထ  သည       င  တစ     မ    လ   င သင      ပ သည   ပည  ရ ဆ သည ။

( န ) ဆရ အတတ ပည  ရ   ဆ သည မ    ဆရ အတတ ပည  ဖင   လ ပ ငန    င စတင ဝင  ရ   မည သ မ     င လ ပ ငန    င    ရ   ရ  နသ မ      သင ယ သ မ      သင ယ မ တ  တ   ရ      ဆ င ရ     င  စရန   လ အပ  သ   အသ ပည ၊  အတတ ပည မ    င မ ၊ စ တ  နသ ဘ ထ    င အ တ    အ      မ    ရရ  စသည  ပည  ရ ဆ သည ။

( ပ ) အ ဝ သင ပည  ရ  ဆ သည မ   ပည  ရ ဆ င ရ  အဖ   အစည  တစ             ပ မ အစ အစ   ဖင  ဆရ   င သင ယ သ တ    အ     သင  ထ     နည  လမ  မ    ဖစ  သ သတင  အ    အလ    င  ဆ  သ ယ  ရ နည  ပည   င  အ    လ ထ  ဆ  သ ယ  ရ မ ဒ ယ နည  လမ  မ      အသ   ပ ၍ သင     မ ၊ သင ယ မ မ     ပ လ ပ  ပ  သ ယ တ င   လ လ သင ယ မ    အ     သည  ပည  ရ   ဆ သည ။

( ဖ ) ရပ ရ  အ    ပ ပည  ရ   ဆ သည မ    သ  ဆ င ရ   ရပ       သ    မဟ တ       ရ  ရ ပည သ မ       ပည  ရ  ဖင   လ  နမ အဆင အတန    တ  တ   စရန   င   အသ ဉ ဏ ပည  မင မ   စရန ယင  တ     ဆ  အ ပ တ င အ     ၍ သင      ပ သည ပည  ရ    ဆ သည ။

( )   တ        ဆ   ဝဖန ပ င        င  သ   အသ ဉ ဏ ရ ၍  ဗလင  တန    ပည စ သည င င သ     င  မ    ဖစ ထ န   ရ      တည  လ   င  ပ ရန ၊
